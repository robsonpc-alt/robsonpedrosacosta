# Robson Pedrosa Costa — Academic Website

Static, responsive academic website prepared for free hosting on GitHub Pages.

## Preview locally
Open `index.html` in a browser, or run a small local server from this folder:

```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Publish free on GitHub Pages
1. Create a GitHub account if needed.
2. Create a public repository named `robsonpedrosacosta` (or `yourusername.github.io` if you want the shortest GitHub Pages address).
3. Upload all files and folders from this site package to the repository root.
4. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.
5. GitHub will show the public URL after deployment.

## Recommended next edits before publication
- Add a professional portrait if desired.
- Add ORCID, Google Scholar, institutional profile, and preferred public email.
- Add DOI/full-text links to key publications.
- If you buy a custom domain later, add it in GitHub Pages settings and update the site metadata/canonical URLs.

## Files
- `index.html` — Home
- `research.html` — Research
- `publications.html` — Publications
- `projects.html` — Projects & networks
- `conferences.html` — Talks and conference presentations
- `teaching.html` — Teaching & supervision
- `cv.html` — CV
- `assets/` — CSS, SVG graphics, and CV PDF

The site uses no external framework or paid service, so it can be hosted free and is easy to maintain.
